🔒 Backup dos dados
Seus modelos, preços e pedidos ficam salvos apenas neste navegador. Use o backup para não perder nada ao trocar de dispositivo ou limpar o cache.
📤 Exportar backup
Baixa um arquivo com todos os seus modelos, preços, configurações e pedidos.
📥 Restaurar backup
Carrega um arquivo de backup salvo anteriormente. Atenção: substitui todos os dados atuais.
💡 Dica: Faça backup sempre que cadastrar novos modelos ou atualizar preços. Guarde o arquivo no Google Drive ou WhatsApp pessoal.
🚀 Publicar no site
Com o token configurado, toda alteração de preço é enviada automaticamente para todos os aparelhos. Os outros dispositivos veem as mudanças ao recarregar o site.
